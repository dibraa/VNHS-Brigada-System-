# Brigada Eskwela System

## Description

The Brigada Eskwela System is a Windows desktop application designed to help schools manage and monitor their Brigada Eskwela activities. It centralizes student information, volunteers, organizations, donations, utilities, academic years, users, and reports in one system.

## Features

- User login and role-based access
- Student information and registration management
- Volunteer and organization record management
- Donation and utility withdrawal tracking
- Academic-year management
- Dashboard summaries and activity monitoring
- Campus map and building information
- Reports for volunteers, donations, and consolidated records

## Technology

- C# Windows Forms
- .NET Framework 4.8
- SQL Server / SQL Server Express
- ADO.NET with `System.Data.SqlClient`
- Microsoft ReportViewer 14
- Typed DataSets and RDLC reports
- Visual Studio legacy project format with `packages.config`
